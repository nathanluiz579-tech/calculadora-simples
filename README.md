# Calculadora Simples

Projeto de calculadora feita com HTML, CSS e JavaScript.

## Operações
- Soma
- Subtração
- Multiplicação
- Divisão

A calculadora verifica se os dois campos foram preenchidos e impede a divisão por zero.

## Como abrir no VS Code
1. Extraia o arquivo ZIP.
2. Abra a pasta `calculadora_simples` no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador. Se tiver a extensão Live Server, clique com o botão direito no arquivo e escolha **Open with Live Server**.

## Como publicar no GitHub
1. Entre em https://github.com/new e crie um repositório público chamado `calculadora-simples`.
2. No repositório, escolha **Add file** > **Upload files**.
3. Envie os arquivos `index.html`, `style.css`, `script.js` e `README.md`.
4. Clique em **Commit changes**.
5. Copie o endereço do repositório para entregar na atividade.

O link ficará parecido com `https://github.com/SEU-USUARIO/calculadora-simples`.
